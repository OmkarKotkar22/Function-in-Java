# 🚀 Java Foundation: Function-Based Algorithms

This repository is a comprehensive collection of fundamental Java programs organized as **Functions** (or **methods** in Java). These functions encapsulate core algorithms for performing mathematical checks, calculations, and array manipulations.

By structuring these solutions as functions, this resource emphasizes **modularity**, **reusability**, and the importance of method definition in object-oriented programming, making it an excellent resource for solidifying Java fundamentals.

## ✅ Function-Based Checks (Number Properties)

This section contains functions designed to check if a given number possesses a specific mathematical or numerical property.

### Key Concepts
* **Encapsulation:** The entire logic for checking a property is contained within a single, reusable function.
* **Boolean Logic:** Many functions return `boolean` (`true` or `false`) indicating the presence of the property.

### 1. Decision Checks

| File Name | Description |
| :--- | :--- |
| `Find_Max_inTwoNo_Function.java` | Finds the **maximum** of two given numbers. |
| `Find_Even_Odd_No_Function.java` | Determines if a number is **Even or Odd**. |
| `Simple_Calculator_Function.java` | Implements a simple **Arithmetic Calculator** using function calls. |
| `Add_2_No_Class.java` | A basic example to **Add two numbers** within a class structure. |

### 2. Specific Property Checks

| File Name | Description |
| :--- | :--- |
| `Check_No_is_Prime_Function.java` | Checks if a number is a **Prime Number**. |
| `Check_Prime_No_Function.java` | Checks if a number is a **Prime Number**. |
| `Check_No_Palindrom_Function.java` | Checks if a number is a **Palindrome**. |
| `Check_Palidrome_Function.java` | Checks if a number is a **Palindrome**. |
| `Check_is_No_Armstrong_Function.java` | Checks if a number is an **Armstrong Number**. |
| `Is_No_Armstrong_Function.java` | Checks if a number is an **Armstrong Number**. |
| `Check_Perfect_No_Function.java` | Checks if a number is a **Perfect Number** (sum of proper divisors equals the number). |
| `Check_No_Neon_Function.java` | Checks if a number is a **Neon Number** (sum of digits of its square equals the number). |
| `Check_Strong_No_Function.java` | Checks if a number is a **Strong Number** (sum of the factorial of its digits equals the number). |
| `Check_Harshad_No_Function.java` | Checks if a number is a **Harshad/Niven Number** (divisible by the sum of its digits). |
| `Check_No_Automorphic_Function.java` | Checks if a number is an **Automorphic Number** (square ends in the number itself). |

## 💻 Getting Started

### Prerequisites
* **Java Development Kit (JDK 8+)** installed.

### Running the Code
1.  Clone this repository:
    ```bash
    git clone [Your Repository URL]
    cd [repository-name]
    ```
2.  Navigate to the program's directory (if applicable).
3.  Compile any Java source file (e.g., for `Check_Prime_No_Function.java`):
    ```bash
    javac Check_Prime_No_Function.java
    ```
4.  Execute the compiled class:
    ```bash
    java Check_Prime_No_Function
    ```
